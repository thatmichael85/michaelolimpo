# Marquee Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship an offline-capable, installable marquee sign generator at `/marquee/` for iPad Air 5.

**Architecture:** New Vite page entry `marquee/index.html` → `src/tools/marquee/`. One `Settings` object drives a resolution-independent `<Display>` that renders text either as DOM/CSS (Smooth) or via a `<canvas>` cell grid with a CSS dot mask (LED/PIXEL). Setup and Play are two views of one React app; `vite-plugin-pwa` generates a service worker scoped to `/marquee/`.

**Tech Stack:** React 19, TypeScript 5.8 strict, Vite 7, Vitest 4 + RTL (jsdom), `vite-plugin-pwa@2.0.0`, `@fontsource/*@5.3.0`.

**Spec:** `docs/superpowers/specs/2026-11-19-marquee-design.md`

## Global Constraints

- No Astryx imports in `src/tools/marquee/`; colours only via CSS variables declared in `src/tools/marquee/marquee.css` (sign colours come from settings and are applied inline — that's data, not styling).
- Setup page is dark mode only.
- No network at runtime: fonts via `@fontsource`, no CDN links in `marquee/index.html`.
- Whole-sign flashing ≤ 3 Hz: blink slow = 1000 ms period, fast = 400 ms; bulb chase step ≥ 400 ms.
- SW scope and manifest `scope`/`start_url` = `/marquee/`; landing page and `/tools/downloadphotos/` get no manifest link and no SW registration.
- `npm test`, `npm run build`, `npm run lint` clean after every task. TDD per `AGENTS.md`.
- Commits on branch `feat/marquee`, no attribution trailers (user memory rule).

## Review Focus

1. **Empty text** — Play button disabled, Display renders nothing, no crash. Test in Task 6.
2. **Very long text at finest dots** — memory stays bounded (cell grid, not a pixel strip); input capped at 500 chars. Test in Task 3.
3. **Corrupt / partial / future-version saved data** — falls back to defaults field-by-field, never throws. Test in Task 1.
4. **Complex emoji** (👍🏽, 👨‍👩‍👧, 🇸🇬, ❤️) stay one unit and are never recoloured. Test in Task 2.
5. **Rotation / resize mid-play** — Display re-measures and re-lays out. Test in Task 4.

  ```ts
  export interface Segment { text: string; emoji: boolean }
  export function segment(text: string, opts: { caps: boolean; singleLine: boolean }): Segment[]; // grapheme-aware (Intl.Segmenter), merges adjacent letters; caps uppercases letters only; singleLine turns \n into ' '
  export function fitScale(content: { w: number; h: number }, box: { w: number; h: number }, axis: 'both' | 'height'): number; // largest scale with content ≤ 92% w (if both) and ≤ 85% h
  export function scrollRate(speed: number): number;  // display-heights per second = 0.15 * speed
  export function scrollDurationMs(travel: number, displayH: number, speed: number): number; // travel px / (rate*displayH px/s)
  export function blinkPeriodMs(rate: BlinkRate): number | null; // off null, slow 1000, fast 400
  export function bulbPositions(w: number, h: number, spacing: number, inset: number): { x: number; y: number }[]; // evenly around the rectangle, corners included once

  ```

### Task 3: LED/PIXEL cell logic

**Files:**
- Create: `src/tools/marquee/led.ts`
- Test: `src/tools/marquee/led.test.ts`

**Interfaces:**
- Produces:
  ```ts
  export interface CellGrid { cols: number; rows: number; data: Uint8ClampedArray } // RGBA per cell, alpha 0 = off
  export function sampleCells(src: { width: number; height: number; data: Uint8ClampedArray }, cols: number, rows: number, threshold?: number): CellGrid; // average each block; lit if mean alpha ≥ threshold (default 0.45*255); lit colour = mean rgb of covered pixels, alpha 255
  export function windowCells(strip: CellGrid, view: { cols: number; rows: number }, offset: number, axis: 'x' | 'y', gap: number): CellGrid; // loops with period strip.cols+gap (x) / strip.rows+gap (y); out-of-strip cells off
  export function stripLength(textCells: number, viewCells: number): { period: number; gap: number }; // gap = viewCells so text fully exits before re-entering
  ```
- [ ] **Step 1: Write failing tests:**
  - 4×2 source, left half opaque red, right half transparent → `sampleCells(src,2,1)` cell0 `[255,0,0,255]`, cell1 alpha 0.
  - a block 40 % covered stays off; 60 % covered is lit.
  - `windowCells` on a 3-col strip with view 5 cols, gap 5, offset 0 → first 3 cells equal strip, cells 3–4 off; offset 8 (period 8) equals offset 0.
  - long text bound: `sampleCells` of a 4000×96 source to 1000×24 returns `data.length === 1000*24*4` (memory proportional to cells only).
